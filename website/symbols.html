05 / YOUR FONT HAS BACKUP

Yes, macOS handles some of the rest.

A visible character doesn't necessarily belong to Monofoki. CoreText can select another font from its font cascade when a glyph is needed. In our macOS checks, fallback included Menlo, Apple Symbols, STIX Two Math and Apple Color Emoji. Those are observations, not a fixed list every app or macOS version must use.

06 / SOMETIMES A SUN IS A SUN

Text or emoji? The string has a say.

Some characters have standardized text and emoji forms. U+FE0E asks for text presentation; U+FE0F asks for emoji presentation. A bare character can use its default presentation or an app's choice. Adding FE0F to an arbitrary missing symbol does not turn it into an emoji.

TEXT / FE0E☀︎ ☕︎ ♥︎U+2600 U+FE0E
EMOJI / FE0F☀️ ☕️ ♥️U+2600 U+FE0F

This preview uses your browser's font fallback. It is not a Terminal.app or iTerm2 rendering test.

Our Perl specimen requests emoji for the 159 non-ASCII characters in these ranges that have standardized emoji sequences. ASCII stays text. It also offers text and native presentation, so you can compare them. Monofoki itself cannot force every application's output into one presentation.

A different question mark: �

U+FFFD is the replacement character. It usually means text could not be decoded correctly, rather than a font lacking the intended glyph. A new font can fill a glyph gap; it cannot recover characters already lost during decoding.
