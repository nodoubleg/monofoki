01 / THE RABBIT HOLE

The font I kept
coming back to.

I went way down the rabbit hole on fonts for my terminal. Monofoki was the Mononoki variant that fit my preferences best: the shapes, the spacing, the little details you notice after staring at code all day.

This is a fork of datMaffin/monofoki, which builds on Matthias Tellen’s Mononoki.

03 / BEYOND ASCII

The rest of
the terminal.

Nerd Font icons bring file types, folders and prompt symbols to the terminal. Monofoki Nerd Font pairs them with the letters and terminal graphics used in apps like Codex, oh-my-pi (omp), and Crush.

Both font variants include 415 added Unicode symbols and all 256 Braille patterns. Choose Monofoki Nerd Font for the Nerd Fonts 3.5.1 icons too. Your operating system can supply emoji and other characters through font fallback.

Leave no [?] behind: see the 415 additions and how font fallback works.

High-density screens are everyday tools now. The point is still the same: clean shapes at the size you actually use, consistent spacing, and no strange gaps in the middle of your terminal.
