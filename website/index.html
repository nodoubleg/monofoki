01 / THE RABBIT HOLE

The font I kept
coming back to.

I went way down the rabbit hole on fonts for my terminal. Monofoki was the Mononoki variant that fit my preferences best: the shapes, the spacing, the little details you notice after staring at code all day.

This is a fork of datMaffin/monofoki, which builds on Matthias Tellen’s Mononoki. The original Mononoki specimen site is the starting point for this one, too.

03 / BEYOND ASCII

The rest of
the terminal.

My terminal needed Nerd Font icons; datMaffin’s build workflow already supported patching those in. Then the missing non-ASCII characters started showing up as odd gaps and fallback glyphs in newer terminal apps like Codex, oh-my-pi (omp), and Crush.

This fork adds all 256 Braille patterns to every style and restores three missing italic arrows. Dotted graphics, box joins, and the surrounding text can finally share the same font.

High-density screens are everyday tools now. The point is still the same: clean shapes at the size you actually use, consistent spacing, and no strange gaps in the middle of your terminal.
